# Systems Designed Game: Moo-ving Violations

A stocks-and-flows board game for System Analysis & Business Modeling. Rival alien crews abduct cows, milk them aboard their saucers, and sell the milk at the Galactic Marketplace. Coins buy seeds, seeds grow grass, and grass keeps cows on the farms. Over-abduct and the shared herd collapses.

## Play the demo

Download `demo/index.html` and open it in any browser. No install needed.

- Arrow keys or the mouse to fly
- Hold Space (or click and hold) to beam up a cow
- `M` to milk, `H` to ship milk home, `N` to end the night

The demo was built before the whiteboard session, so it doesn't have grass, seeds or the Marketplace yet. See the spec sheet for the current design.
