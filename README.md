# Systems Designed Game: Moo-ving Violations

A single-player digital stocks-and-flows game for System Analysis & Business Modeling. You pilot a UFO, abduct cows, upgrade them up the flavor ladder (Regular → Chocolate → Strawberry → Almond → Donut), milk them, and sell the milk at the Galactic Marketplace. Every abduction raises suspicion; hit 10 and you lose everything in the UFO. Score as many coins as you can in 10 visits.

## Play the demo

Download `demo/index.html` and open it in any browser. No install needed.

- Arrow keys or the mouse to fly
- Hold Space (or click and hold) to beam up a cow
- `M` to milk, `H` to ship milk home, `N` to end the night

The demo is an early prototype. It still uses nights and fuel and doesn't have cow flavors, power-ups or the Marketplace screen yet. See the spec sheet for the current design.
